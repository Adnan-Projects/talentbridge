# Video Placeholders Directory

Place your MP4 video files directly in this directory:

1. `violin-teacher.mp4` — The Power of Music (Violin teaching showcase)
2. `dance-teacher.mp4`  — Moving Beyond Boundaries (Dance teaching showcase)
3. `football-coach.mp4` — Dreams Beyond the Field (Football coaching showcase)

The `VideoSection` component automatically tests for the presence of these files. Until they are placed here, an attractive interactive placeholder with a test/play trigger and in-browser local file upload selector is displayed.
